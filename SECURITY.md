# Security

## Reporting a Vulnerability

Information security is a team effort. If you discover a security vulnerability in this project, please report it to us via Jamf's Vulnerability Disclosure Program so we can fix it.

[https://www.jamf.com/security/vulnerability-disclosure/](https://www.jamf.com/security/vulnerability-disclosure/)

For more information about Jamf's broader security program, please see:

[https://security.jamf.com/](https://security.jamf.com/)
